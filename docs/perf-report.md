## 一、已落地且带前后对照的收益

| 改动 | 效果 | 验证方式 |
|---|---|---|
| GPU 熔断按效果隔离（失败按**同名效果**连续计数；隔离时清零全局 streak） | 修掉"一个坏 shader 关掉整链"：3641860575 GPU 8590ms → **6828ms** | 同场景 CPU/GPU 对照 + 全库普查 |
| 退化效果负缓存（`effects.skipDegenerateAfter`，默认 0=关） | 反复渲染同一场景时跳过"算完必被丢弃"的效果：3486806915 **−38%**、3641860575 −33%、3640755971 −45% | **像素逐字节一致**（sha1 比对） |
| 片元写 varying 归一（`normalizeWrittenVaryings`） | 解封 5 个图层的 GPU 加速；全库 GPU 可编译 **191 → 195** | 全库编译审计 + CPU 普查不变 |
| DX 向量维度归一（`truncateToDeclaredDim`） | 全库 GPU 可编译 **195 → 206**（+11） | 数值验证与 CPU 解释器 `declInit`(P1-35) 的 HLSL 截断一致 |
| GPU 输出退化兜底（`looksDegenerate`：整幅同一 RGBA / **覆盖度塌陷**，两条都带 alpha） | 拦住"编译期失败被推后成运行期退化"的漏放；`degenerate` 计数可观测 | 修复前后降级数对照（曾漏放 4 个全透明帧） |
| 退化拒绝不计熔断 + 逐效果"输出不可信"拉黑 | 拒绝次数 **8 → 2**；不再因单效果把整链 GPU 关掉 | gpuStats 计数对照 |
| 删除冗余 `gl.finish()` | **无性能收益**（实测开销≈0）—— 属清理，把"已实测非热点"写进注释以免重查 | 单 pass 前后计时 |

## 二、三条关键结论（决定后续该往哪投人）

1. **整帧约 3/4 耗时与输出分辨率无关。**
   3641860575：320×180 6714ms / 480×270 6426ms / 960×540 9440ms / 1920×1080 22149ms。
   输出像素 ×4 只多 47% ⇒ 时间花在按**输入纹理**尺寸跑的 CPU 逐像素效果上
   （foliagesway/waterflow/depthparallax 的输入是 **1.27 Mpx**，为 480×270 输出的 10 倍）。

2. **GPU 增益只在小分辨率存在**（`runEffectOnGL` 每 pass 全尺寸上传 + readPixels 回读，
   成本随输入像素数线性增长，吃掉了着色器优势）：
   | 输出 | CPU | GPU |
   |---|---|---|
   | 480×270 | 7273ms | 6392ms（−12%） |
   | 1920×1080 | 22359ms | 22578ms（**+1%，零增益**） |
   纯 shader 侧很便宜（1080p 单 pass 2.96ms、26 pass ≈78ms）⇒ **贵的是搬运**。

3. **"能编译"≠"该启用"**：把在 CPU 侧编译期失败的 shader 变成 GPU 可编译，
   会把"效果未应用"推后成"运行期退化"，而退化保护在"输入本身是单色"时豁免
   ⇒ 必须先用输出退化兜底接住（本轮已补，且判据必须带 alpha）。

## 三、仍未落地（按"收益/风险"排序，供决策）

| 方向 | 预期收益 | 代价/前置条件 |
|---|---|---|
| **纹理侧降采样**（效果链输入降到 N 像素预算） | 256² 预算 **−43.7%**；512² −35% | **改像素**（256² 差 50.97%、平均绝对差 6.85；512² 差 16%、绝对差 1.20）。需产品决策 |
| **多 pass 中间 RT 留 GL 侧** | 让 GPU 在高分辨率下重新有效（当前 1080p 零增益） | 工作量中等偏大；**前置条件未成立**：本机场景里多 pass 效果多被"同类 shader 编译失败"拉黑后走 CPU，改完无法验证 |
| **解开剩余 35 个"只能走 CPU"的效果** | 逐项 GPU 化 | 主要是 `vecN op vecM` 的**操作数级**维度对齐。⚠ 我做过的朴素版本（按 token 直接补 swizzle）会**破坏合法表达式**（used 23→87、failed 10→33），必须做成"识别运算两侧维度不等且可静态确定"的精确重写，并用**逐效果 CPU/GPU 输出对照**验收 |
